# Wiki

A personal, LLM-maintained wiki about msilva's work at Livemode — projects,
systems, decisions, people, and meeting notes, kept current by Claude Code
running against the schema in `CLAUDE.md`.

- **[`CLAUDE.md`](CLAUDE.md)** — the schema. Governs how this vault is read,
  written, and organized; start there to understand the structure.
- **[`index.md`](index.md)** — catalog of every page, updated on every write.
- **[`log.md`](log.md)** — append-only record of every operation performed on
  the vault.

Raw source material lives outside this repo (`C:\Users\msilva\Documents\raw\`)
and is never committed here.
