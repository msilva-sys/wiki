## Comparison against [[Fluxo Agêntico diagram]]

Checked side by side, node by node. **No structural or content differences
found**: same 14 agents, same roles, same three branches (OPERACIONAL /
ENABLEMENT / PROJETOS), same four entry channels, same colors-by-group, same
two named dashed context-edges (`A5 → A3 "retroalimenta execução"` and
`A13 → A1 "contexto"`), same legend (*"Linhas sólidas = fluxo principal ·
Linhas pontilhadas = alimentação de contexto"*).

**One addition, folded into the other page instead of duplicated here:**
this render shows two side-annotation labels next to the PROJETOS pipeline
that the other page's table didn't call out individually — **`Desenvolvimento`**
next to A8 Orchestrator and **`Sub-agentes`** next to A9 Developer, alongside
the already-recorded `Novos sistemas` next to A7 Discovery. Added to
[[Fluxo Agêntico diagram]]'s table.

Being an earlier version with no found content differences, this page exists
mainly as a provenance record — [[Fluxo Agêntico diagram]] remains the
canonical write-up (Mermaid reconstruction, full agent table, the "four
things the diagram says" analysis, open questions).
